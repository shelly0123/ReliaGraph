Trust policy

How this prototype treats information

01Evidence first

Every stored candidate relation should retain a supporting chunk and source identifier.

02Conflicts stay visible

Competing source statements remain inspectable; no automatic “truth winner” is assumed.

03Documents are data

Text that attempts to instruct the system is treated as untrusted content and may be quarantined.

04Abstention is valid

When the system lacks evidence or a required language model, it should say so.
